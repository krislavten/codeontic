系统地图——每条链路、每个 loop 都能点开

这张图把系统拆成一个个 loop——会自己往前走的循环：状态机、轮询、重试链、渲染循环都算。若干 loop 按执行先后接起来，就是一条链路：用户走完的一段完整旅程。

点开任何一条链路或一个 loop，就能看到它的详情：在做什么、代码在哪、有没有测试守着、落实到了什么程度。链路详情里还能一步步点进它经过的每个 loop。

已落实：代码、测试都有 半落实：有代码，缺测试 有缺口：代码或测试没接上

每条链路里的 loop 按执行先后排列。链路下方的小签是「交接点」——两个 loop 交棒的位置，最容易出问题，所以模型把它们单独记录、单独打分。

进这一栏只有一个原因：没有任何链路用到它。它可能真是独立运转的后台机器，也可能只是还没被画进某条旅程——归在这里不代表它不重要。按代码包分组；↳ 表示内嵌在别的 loop 里的子循环。

这里集中了图上所有没守住的地方——记录在案的旧账，和代码或测试还没接上的节点。每一条都在等一个人拍板：修掉、删掉，还是先认下。
